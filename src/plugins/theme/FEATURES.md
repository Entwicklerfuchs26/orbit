## Theme-Sets (SetEditor)
- [ ] Plugin aktivieren → Menüpunkt **Design** öffnet den Set-Editor
- [ ] Set anlegen/bearbeiten: Farbe, Hell/Dunkel, Wallpaper, Schrift, Dichte, Animationen
- [ ] Palette automatisch aus einer Farbe oder einem Wallpaper (Material You)
- [ ] Aktives Set färbt die ganze App; bleibt nach Reload erhalten

> Hinweis: Steht bislang im Schatten der automatischen SKWD-Wall-Theming-Palette.
> Eigene Testfälle werden ergänzt, sobald das Design-Plugin aktiv ausgebaut wird.
